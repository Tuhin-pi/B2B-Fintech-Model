This project aims to predict the credit limit of business clients based on their transaction history and financial behavior using advanced machine learning techniques.

📌 Key Highlights
🧠 Built an end-to-end ML pipeline: Includes data ingestion, cleaning, preprocessing, training, evaluation, and deployment-ready packaging.

📊 Performed Exploratory Data Analysis (EDA): Used multivariate and bivariate analysis to extract key financial patterns.

🔧 Feature Engineering & Selection: Applied encoding techniques, correlation analysis, and statistical methods for optimal feature selection.

🚀 Modeling with XGBoost Regressor: Achieved over 85% prediction accuracy, leveraging ensemble learning and hyperparameter tuning.

📦 Modular and Scalable Design: The codebase is structured for reproducibility and ease of experimentation.

🛠️ Tech Stack
Python, Pandas, NumPy, scikit-learn, XGBoost

Matplotlib / Seaborn for visualization
